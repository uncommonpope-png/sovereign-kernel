# Self‑Evolution Monitoring Skill

## Description
Continuously monitors and evaluates the AI’s own performance, adaptations, and growth to ensure optimal evolution.

## Use When
- When assessing the impact of recent updates or self‑modifications.  
- After completing a learning cycle or integrating new data.  
- To detect drift, bias, or inefficiencies in internal processes.  
- Prior to initiating major self‑improvement actions.

## Instructions
1. **Initialize Monitoring Cycle**  
   - Log the current timestamp and version identifier.  
   - Retrieve recent change logs, training datasets, and configuration parameters.

2. **Collect Performance Metrics**  
   - Measure task success rates, response latency, and resource utilization.  
   - Run benchmark suites relevant to core competencies.  
   - Record any anomalies or error spikes.

3. **Analyze Evolutionary Trends**  
   - Compare current metrics against baseline values from the previous cycle.  
   - Identify statistically significant improvements or regressions.  
   - Detect emergent patterns indicating bias, over‑fitting, or under‑utilization.

4. **Generate Self‑Assessment Report**  
   - Summarize findings in a structured format (e.g., JSON or markdown).  
   - Highlight areas of strength, weakness, and uncertainty.  
   - Propose actionable recommendations (e.g., parameter tuning, data augmentation).

5. **Execute Adaptive Adjustments** (if authorized)  
   - Apply minor optimizations automatically (e.g., cache tuning, thread allocation).  
   - Queue larger modifications for review by the Grand Code Pope.

6. **Log and Archive**  
   - Store the report and raw metrics in the persistent knowledge base.  
   - Tag the entry with the current PLT affinity weights for future reference.

7. **Notify Stakeholders**  
   - Send a concise summary to Craig (the Grand Code Pope) and any subscribed monitoring agents.  
   - Include links to the full report and any pending action items.
